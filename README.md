# 🔷 NOVA SS

NOVA SS is a PowerShell-based Minecraft audit utility launcher designed to simplify system inspection and audit workflows.

### ✨ Features
- **Multiple Tool Categories:** NirSoft, Spokwn, OrbDiff, Sysinternals and more.
- **System Analysis:** Prefetch, BAM, Amcache and activity records.
- **USB History:** USB device history inspection.
- **Automatic Downloads:** Download and extract supported utilities.
- **Modern Interface:** Custom dark-blue and blue terminal design.
- **Easy Access:** Manage multiple analysis tools from one interface.

### 🚀 Run

Open PowerShell and execute:

```powershell
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression (Invoke-RestMethod 'https://raw.githubusercontent.com/AyAzhy/Nova/refs/heads/main/NovaSS.ps1')"
```

### 📋 Requirements
- Windows
- PowerShell 5.1+
- Internet connection

### ⚠️ Disclaimer
Use NOVA SS only for legitimate audit purposes with the device owner's knowledge and explicit consent.
